KWIKAR WEBSITE — HTML / CSS / JS
=================================

What is inside
--------------
public_html/   The complete website. Upload everything in this folder to Hostinger.
source/        build.py + catalog.json, used to regenerate pages after content changes.
               (Not needed on the server.)

No admin panel, no online payment. Every booking and enquiry form opens
WhatsApp (+971 50 559 9243) with the customer's details filled in.


Upload to Hostinger (one time)
------------------------------
1. hPanel > Websites > kwikar.com > File Manager > open public_html.
   (Back up / remove the old site files first.)
2. Upload the CONTENTS of the public_html folder from this zip
   (including the hidden .htaccess files in public_html, api/ and api/cache/).
3. Live tours and prices (TravelDesk):
   - In public_html/api/ copy  config.sample.php  to  config.php
   - Open config.php and paste the TravelDesk API key between the quotes
     ('KWIKAR_API_KEY' => 'your-key-here').
   - Make sure the folder public_html/api/cache is writable (755 is normal).
   - Test: open https://kwikar.com/api/tours.php — it should start with {"ok":true
   Tours, prices, ratings and tour photos come ONLY from this API. Without the
   key, tour sections show "Tours could not be loaded" with a WhatsApp button;
   holidays, transfers, visas and all other pages work normally.
4. Hostinger plan must have PHP (Premium has it). Only api/tours.php and
   api/sitemap-tours.php use PHP; everything else is plain HTML.
5. Google Search Console: submit https://kwikar.com/sitemap.xml and
   https://kwikar.com/api/sitemap-tours.php

Changing content (holidays, cars, visas, destinations)
------------------------------------------------------
Edit source/data/catalog.json, then run:   python3 source/build.py
It rewrites the HTML pages in public_html. Upload the changed files.
(Or simply ask Claude to make the change.)

How tours work now (SEO update, 29 Oct 2026)
--------------------------------------------
- source/build.py reads the tours API (https://kwikar.com/api/tours.php, which
  reads TravelDesk) and writes every tour page, listing and sitemap as HTML, so
  Google, Bing and AI tools can read prices, options, FAQs and terms.
- Tour pages live at /activities/{city}/{slug}; old /tour/{id} links 301 to them.
  Slugs are saved in source/data/tour-slugs.json so a URL never changes.
  Removed tours return 410 Gone.
- GitHub Action "Refresh tours" rebuilds every 3 hours and deploys if anything
  changed. Run it by hand from the Actions tab after big price changes.
- Optional hand-written content per tour (quick answer, visitor info, KWIKAR
  tip, extra FAQs, custom title/slug, last-checked date): source/data/tour-extras.json
- Analytics / Search Console / Bing: put the IDs in source/data/site-config.json.
