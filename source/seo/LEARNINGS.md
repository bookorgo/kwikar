# SEO learnings

Short, factual notes that later runs should follow.

- SEO text must sit inside the site's own section design (eyebrow + heading + rule, fact rows, cards, FAQ cards). Plain long articles and duplicate tables looked "odd" to the owner (30 Oct 2026).
- Put long hub text below the listings, not above; visitors come for the tours first.
- Don't repeat the same list twice on a page (e.g. options table + option cards).
- Supplier data can be wrong (e.g. a private car option listed as "1 hour"); hide such automatic glance rows with glance_hide and state the checked fact instead.
- Photos come from the supplier API in a fixed order; check the actual images before writing alt text.
- Browsers may show a cached page after a deploy; HTML is now served with Cache-Control: no-cache.
- In unattended runs WebFetch to globalvillage.ae, visitdubai.com and mediaoffice.ae was blocked (permission prompt unanswered); arabianbusiness.com worked. Cross-check news facts with the supplier offer notes in the feed (`details.<id>.offers[].desc`) and leave out anything only one unofficial source states.
- Earlier hand-written glance rows can be wrong (Global Village hours said Mon–Thu/weekends; real split is Sun–Wed / Thu–Sat). Re-check old rows when you fill a page.
- dubaiframe.ae/en/plan-your-visit and emirates.com (Dubai Experience pages) could be fetched in unattended runs; the TravelDesk image CDN is blocked from the sandbox, so alt text needs a run that can view the photos. Supplier FAQs can contradict supplier offer notes (Dubai Frame 9am vs 8am): use the official page.
- qa.py passed a 171-char meta description; check the rendered length yourself.
- Run of 30 Oct 16:30 UTC: thedubaiaquarium.com could not be fetched (permission prompt unanswered); uae.emaar.com and emirates.com/bh/... Dubai Experience pages worked. When sources disagree on hours (Aquarium 10pm vs 11pm), say "open every day, our team confirms the time" instead of a time.
- Screenshot via a local server (`python3 -m http.server` in public_html); file:// loses the CSS because asset paths are absolute.
- Run of 30 Oct 17:10 UTC: every WebFetch (dubaiframe.ae, uae.emaar.com, atthetop.ae) was blocked by an unanswered permission prompt. Itinerary-style guides can still ship by reusing only facts already checked and sourced in tour-extras.json; leave out anything new (e.g. Dubai Fountain times).
- Run of 30 Oct 18:20 UTC: atlantis.com and visitdubai.com were blocked, but dubaipass.visitdubai.com (Dubai Tourism's Dubai Pass product pages, e.g. /za/dubaipass/attractions/...) could be fetched and has hours, rules and dress codes. Find the page with WebSearch first. `choose` must be a list of [label, text] pairs, not a string (build crashes).
- Editor 3 Nov: count the title *including* " | KWIKAR" (9 chars) — four guide/tour titles were 62–65 chars. Avoid "cheapest" even in a factual comparison; say "costs the least". Meta descriptions must reach 120 chars too (one was 119).
- Writer 4 Nov: check what sets {from} before using it. On Ferrari World the cheapest offer is a Fast Track add-on that needs a separate entry ticket, so {from} would mislead; hide the Price glance row and say "live price of each option below". ferrariworldabudhabi.com/en/park-overview/rides-information could be fetched (ride closures); its hours page is JavaScript-only. Big rides can be closed for months (Formula Rossa since May 2026): check ride-status pages before praising a ride.
- Writer 4 Nov: in kids/family content check the feed price per tour: for KidZania the "price" is the adult rate and the child ticket costs more, so don't quote {price:275}. A glance list that repeats the body's age table counts as a duplicate list; give the glance different facts. Official attraction sites (kidzania.ae, legoland.com, imgworlds.com, skidxb.com, dubaisafari.ae, thegreenplanetdubai.com) were all blocked.
- Editor 4 Nov: supplier redemption notes said "you will instantly receive tickets" (9 pages); qa.py only caught "instant confirmation". build.py now rewrites it; in hand-written text never promise instant tickets — tickets follow our team's confirmation and payment. WebFetch was blocked for every host in this unattended Editor run, so re-checks relied on the feed.
- Tech 5 Nov: the feed's listing `price` is simply the cheapest offer, which can be a fast-track add-on (Yas parks) or an adult escort rate (KidZania). build.py now skips add-ons and supports `from_price: "child"` / `from_exclude`; when a new tour's From price looks too low, check its offers before writing {from}.
- Auditor 5 Nov: the sandbox proxy re-signs TLS (issuer "Anthropic Egress Gateway") and blocks www.kwikar.com and crt.sh, so SSL expiry and the www redirect cannot be checked from a run; don't report the proxy's 30-day certificate as the site's. site_audit.py now flags repeated words ("experiences Experiences") and "tour form" typos in titles/H1s, also on noindex pages.
- Writer 5 Nov: www.louvreabudhabi.ae page URLs failed, but louvreabudhabi.ae/en/visit/plan-your-visit (no www), the prod-cm.louvreabudhabi.ae visitor-regulations PDF and experiences.visitdubai.com/productDetail/<id> could be fetched. Find host/mirror variants with WebSearch before giving up on an official site. The auto "Runs on: Every day" glance row is wrong for attractions with a closing day (Louvre: Mondays); hide it.
- Trustpilot: only the Review Collector widget (footer) is allowed until the account has real reviews; do not add star/"Excellent" widgets or aggregateRating without Irfan's approval (5 Nov 2026).
- Writer 5 Nov: www.dubaimiraclegarden.com (home, /faq, /experiences/*, /butterfly-garden) could be fetched, but FAQ answers are collapsed (not in fetched text); use the home page "Know before you go" block. Official child band (3–12) differed from the supplier (3–11), so only "under 3 free, child ticket from 3" was stated.
- Editor 5 Nov: don't answer "Is it open now?" FAQs with "Yes" (goes stale); state the dates. Don't state ticket validity (e.g. "valid until end of season") unless the supplier notes say it; add "our team confirms the validity". WebFetch (louvreabudhabi.ae, dubaimiraclegarden.com) and the image CDN were blocked in this unattended run.
